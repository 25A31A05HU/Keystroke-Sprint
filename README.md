# Keystroke-Sprint ⌨️

A lightweight, offline-ready typing speed tester built entirely with Vanilla JavaScript. Designed to benchmark typing speed and accuracy with strict keystroke tracking and a modern developer-focused UI.

**Key Features:**
- ⚡ **Zero-Latency Offline Mode:** Uses a built-in text library instead of relying on external APIs.
- ⏱️ **Real-Time WPM Tracking:** Calculates Words Per Minute dynamically as the user types.
- 🎯 **True Accuracy Calculation:** Analyzes individual keystrokes against the total characters typed, preventing artificial score inflation.
- 🌙 **Modern UI/UX:** Features a custom dark-mode aesthetic with active UI state changes to prevent user errors during active tests.
